Public GitHub CI & SLSA Provenance

dejavu is 100% open-source and compiled directly on public GitHub Actions runners from this repository. Every release ships cryptographic SLSA Build Provenance Attestations and a published SHA256SUMS.txt checksum file you can independently verify.

Zero Suspicious Dropper or Script Flags

Android REQUEST_INSTALL_PACKAGES and PackageInstaller self-installer code have been completely removed (with allowBackup="false" & system-CA TLS config). Windows binaries remove WScript.Shell & hidden batch scripts, adding full Win32 VersionInfo, asInvoker manifest, and /highentropyva+.

Why OS Prompts Can Still Appear

Because indie open-source .exe and .apk releases do not yet carry a paid commercial Authenticode certificate or Google Play Store listing, Windows SmartScreen (“Unknown publisher”) or Android sideload notices can still appear. Always compare the SHA-256 hash against SHA256SUMS.txt before installing.

Verify SHA-256 (PowerShell) Get-FileHash .\dejavu-Setup.exe -Algorithm SHA256
